Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# Accessible HRMS Portal

An accessibility-first Human Resource Management System (HRMS) prototype designed to create a more inclusive enterprise experience for everyone, especially keyboard users, screen reader users, blind users, and people with low vision.

This project was inspired by real accessibility challenges faced by employees while using enterprise HRMS platforms in their daily work life.

---

## Project Vision

Most HRMS portals are heavily used inside organizations for:

- Attendance management
- Leave applications
- Payroll access
- Document downloads
- Employee workflows
- Organization hierarchy
- Internal operations

But accessibility is often treated as an afterthought.

The goal of this project is to build an enterprise-grade HRMS where accessibility becomes part of the product architecture from the beginning.

---

## Accessibility Features

- Keyboard accessible navigation
- Visible keyboard focus indicators
- Screen reader friendly validation
- Semantic HTML structure
- Accessible forms and workflows
- Error identification and suggestions
- Focus management on validation errors
- Proper color contrast
- Autocomplete support
- Responsive UI
